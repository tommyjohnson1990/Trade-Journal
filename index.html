How to export from MetaTrader 5
Deals Export (recommended)
1. Open MT5 → View → Terminal
2. Click the History tab
3. Right-click → Save as Report
4. Choose CSV format
5. Upload the .csv file here
Positions / Statement Export
1. Open MT5 → Account History
2. Right-click the history list
3. Click Save as Detailed Report
4. Export as CSV
5. Upload the .csv file here
✦ Both tab-separated and comma-separated MT5 exports are supported. Open positions (no exit price yet) are imported as partial entries.
